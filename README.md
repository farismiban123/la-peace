Fungsi:

Agregator data kemanusiaan: menyediakan platform terpusat yang menyajikan update krisis kemanusiaan serta data dampak konflik secara terstruktur.

Kurasi jalur donasi kredibel: menghubungkan publik langsung ke portal resmi lembaga kemanusiaan tepercaya untuk menghindari penipuan atau donasi bodong.

Koleksi terpersonalisasi: memfasilitasi pengguna untuk menyimpan dan memantau program bantuan yang ingin mereka dukung secara berkala.


Tujuan:

Bagi Pengguna: tidak perlu bingung mencari ke mana harus menyalurkan bantuan; informasi korban dan tautan lembaga donasi resmi sudah terverifikasi di satu tempat.

Bagi Mitra/Organisasi Donasi: mendapat eksposur tambahan tanpa biaya integrasi sistem.

Bagi Penilaian Projek Kuliah: memenuhi seluruh aspek web dinamis—autentikasi (session/token), relasi basis data many-to-many, dan operasi CRUD penuh (terutama pada fitur simpan/bookmark).
